## Summary

Make GPy tutorial plots run in a current Jupyter kernel **without Chart Studio
credentials**. In this repository that means switching tutorial cells from
`change_plotting_library('plotly')` (online) to `'plotly_offline'` or
matplotlib. Two remaining failures live in **GPy**, not in these notebooks;
this CIP records them as blockers and the notebook-side workaround.

## Motivation

After CIP-0001 syntax is fixed, three tutorials still cannot plot:

| Notebook | Cell / library choice | Failure on GPy 1.15.0 + Plotly 7 |
|----------|------------------------|----------------------------------|
| `basic_gp.ipynb` | `change_plotting_library('plotly')` | GPy `PlotlyPlotsOnline.show_canvas` calls removed `plotly.plotly.iplot` |
| `models_basic.ipynb` | same | same path once a figure is shown |
| `MagnificationFactor.ipynb` | same, then matplotlib | Plotly 7 rejects `marker.size` as the string `'5'` (GPy `plotly_dep/defaults.py`) |

The notebooks chose `'plotly'` when that meant “figures in the notebook”. In
current GPy it selects the **online** backend. Tutorials should not require a
Plotly Cloud account.

## Detailed Description

### Notebook-side change (this repo)

1. In `basic_gp.ipynb`, `models_basic.ipynb`, and `MagnificationFactor.ipynb`,
   replace `GPy.plotting.change_plotting_library('plotly')` with
   `'plotly_offline'` **or** `'matplotlib'`.
2. Prefer **matplotlib** where the notebook is a simple 1D/2D GP plot
   (`basic_gp`, `models_basic`) so CIP-0003 CI does not need a browser or
   Plotly widgets. Prefer **plotly_offline** in `MagnificationFactor` if that
   notebook's point is the Plotly layout; otherwise matplotlib there too.
3. Drop saved Plotly display objects from old outputs when clearing cells
   (CIP-0001).

Default recommendation: **matplotlib for all three** unless a Plotly-specific
lesson is essential. That unblocks tutorials even if GPy's Plotly backend
stays broken for a cycle.

### GPy-side blockers (not implemented in this repository)

These remain true even after the notebook switch if anyone still calls
`'plotly'` or uses Plotly latent plots:

1. `GPy/plotting/plotly_dep/plot_definitions.py` — `PlotlyPlotsOnline` uses
   `plotly.plotly.iplot` / `.plot`. Chart Studio is a separate package.
2. `GPy/plotting/plotly_dep/defaults.py` — `size="5"` / `size="0"` strings.
3. `change_plotting_library('plotly')` aliases the online class.

Track those as a **GPy issue or CIP** against SheffieldML/GPy. Do not patch
GPy from this repository. CIP-0003 may still skip Plotly-heavy cells until
that GPy change exists, if we keep plotly_offline in MagnificationFactor.

### Non-goals

- Rewriting GPy's plotting stack.
- `lab_classes` plotting.
- Interactive heteroscedastic widgets beyond the `fmt="none"` cell fix in
  CIP-0001.

## Implementation Plan

1. Decide matplotlib vs plotly_offline per notebook (proposal: matplotlib
   unless MagnificationFactor needs Plotly layouts).
2. Edit the `change_plotting_library` cells; remove Chart Studio / `plotly.plotly`
   instructions from nearby markdown if present.
3. Open a GPy issue listing `plotly.plotly.iplot` and string marker sizes;
   link it here.
4. Execute with CIP-0003. If MagnificationFactor still hits string `size`
   under plotly_offline, switch that notebook to matplotlib or wait for the
   GPy fix.

## Backward Compatibility

Rendered GitHub/nbviewer pages change only where old Plotly HTML outputs are
cleared. Readers without Plotly can run matplotlib tutorials with
`gpy[plotting]` (matplotlib is the GPy default).
