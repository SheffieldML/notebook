## Summary

In **this** repository (`SheffieldML/notebook`), keep the GPy tutorial
notebooks under `GPy/` as source cells: strip executed outputs on commit, and
add an Open in Colab badge on each of those tutorials. This is not a change to
the GPy library. Lab classes, computational biology, and other trees in this
repo are unchanged.

## Motivation

Stored outputs hide source-cell diffs when we use these tutorials as a test
surface for a GPy release. Colab badges let a reader open a tutorial from this
repository in the browser.

## Detailed Description

**Scope:** `GPy/*.ipynb` in SheffieldML/notebook (the tutorial set). Not
`lab_classes/`, `compbio/`, `GPy-phil/`, or the GPy library repo.

**nbstripout via pre-commit.** `.pre-commit-config.yaml` runs
[nbstripout](https://github.com/kynan/nbstripout) 0.9.1 on `GPy/*.ipynb`.
Contributors run `pre-commit install` once.

**Colab badges.** Each tutorial in `GPy/` gets a badge that opens that file
from SheffieldML/notebook on the default branch `main`. `GPy/index.ipynb`
also has a badge next to each tutorial link.

## Implementation Plan

1. Add `.pre-commit-config.yaml` with nbstripout on `GPy/*.ipynb`.
2. Strip existing outputs in those tutorials.
3. Insert Colab badges in each `GPy/` tutorial and in `GPy/index.ipynb`.
4. Note the hook and Colab in the README GPy tutorials section.

## Backward Compatibility

GitHub / nbviewer views of the tutorials lose stored plots until the reader
runs the notebook. Colab opens `main`, so badges on this feature branch show
published `main` until merge.

## Testing Strategy

- After strip, `GPy/*.ipynb` code cells have empty outputs.
- Badge links open SheffieldML/notebook, path `GPy/<tutorial>.ipynb`, branch
  `main`.
