## Summary

Add a top-level `GPc/` tree beside `GPy/` that ports the **documented GPy tutorial subset** to the `gpc` Python façade. Notebooks are both teaching material and an executable parity test (same spirit as CIP-0003 for GPy).

**First cut (in scope):** `basic_gp`, `sparse_gp_regression`, and an `index` that maps each GPy notebook to GPc status (done / deferred / out of subset).

**Phase C (a8 façade):** ICM / `GPCoregionalizedRegression`, MAP GPLVM, collapsed Bayesian GPLVM, MRD, DeepGP (CIP-0035).

**Explicit non-goals (match GPc CIP-0015 / REQ-0009):** Poisson, heteroscedastic, integral kernels, HMC, GPy `config`, sparse EP classification, full SVGP notebook until Phase 5 surfaces land, SVI Bayesian GPLVM (CLI-first).

## Motivation

GPc already treats SheffieldML GPy notebooks as the **spec/checklist** (native demos in GPc CIP-0015; Python façade in CIP-001D). A few examples live under `GPc/python/examples/`, but teachers and Colab users discover tutorials here. Putting a parallel `GPc/` tree in this repo:

1. Makes GPy → GPc porting a side-by-side click, not a scavenger hunt.
2. Gives maintainers an end-to-end smoke: install `gpc`, run notebooks, compare narrative and numbers to the GPy twins.
3. Keeps GPc’s native CLI/markdown tutorials as the primary share format for C++; Jupyter stays the Python share surface.

## Detailed Description

### Layout

```
GPc/
  index.ipynb                 # checklist + Colab badges
  basic_gp.ipynb              # ↔ GPy/basic_gp.ipynb (1-D + 2-D Matérn ARD + matplotlib slices)
  sparse_gp_regression.ipynb  # ↔ GPy/sparse_gp_regression.ipynb (DTCVAR default)
  coregionalization_toy.ipynb # ICM / LCM + IndexWhite
  gplvm_oil100.ipynb          # MAP GPLVM + pods oil_100
  bgplvm_oil100.ipynb         # collapsed Bayesian GPLVM
  mrd_toy.ipynb               # multi-view MRD
  deepgp_sinc.ipynb           # DSVI DeepGP (a8)
  README.md                   # install notes, subset table, link to GPc repo
```

**Phase B:** `basic_kernels`, olympics/`pods` twins, ExpQuad naming, weight-space ridge, classification.

**Phase C (this branch):** coregionalization, GPLVM, BGPLVM, MRD, DeepGP; pin `gpc==0.1.0a8`.

Still later: `models_basic` (needs Python `fix`).

### House style (align with CIP-0004 / 0006)

- Colab badge pointing at `SheffieldML/notebook` `main` (or PR branch while drafting).
- First code cell: try `import gpc`, else install (PyPI when published; TestPyPI alpha pin with `--extra-index-url` until then). Do **not** unconditional `%pip` on every CIP-0003-style CI run.
- `OPENBLAS_NUM_THREADS=1` (and document nesting with OpenMP).
- Prefer `gpc.kern.*` + `gpc.models.GPRegression` / `SparseGPRegression`; path get/set (`set_by_path` / `param_paths`) instead of GPy `__getitem__`.
- Plotting via `gpc.plot.plot_1d` + matplotlib (optional extra), not a full GPy plot surface.
- Call out differences in markdown: `objective()` is **−log-likelihood**; CIP-0027 noise is `likelihood.variance`; sparse default approx is `dtcvar`.
- Strip outputs on commit (`nbstripout` for `GPc/*.ipynb`).

### Relationship to GPc repo examples

`SheffieldML/GPc/python/examples/*.ipynb` remain **developer/smoke** notebooks next to the package. This tree is the **public tutorial index**. Prefer linking rather than duplicating forever; when a notebook matures here, GPc can point its subset checklist at `notebook/GPc/…`.

### Testing

Mirror CIP-0003: `scripts/run_gpc_tutorials.py` + GitHub Actions workflow that installs a pinned `gpc` wheel (TestPyPI or artifact) and executes `GPc/*.ipynb` with `MPLBACKEND=Agg`. Skip notebooks marked deferred in the index.
